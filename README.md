# DevOps Deployment Dashboard

Учебный проект по методологии DevOps.

Цель: автоматическая проверка, сборка и развёртывание веб-приложения
с помощью GitHub Actions, Docker и Nginx.


## План 

1. Git: ветки и Pull Request.
2. GitHub Actions: автоматическая проверка проекта.
3. Docker: сборка образа и запуск контейнера.
4. Автоматическое развёртывание на учебном сервере.
5. Nginx и HTTPS.
6. Мониторинг через Prometheus и Grafana.
